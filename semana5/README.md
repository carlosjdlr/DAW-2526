# Galería Interactiva con JavaScript

Proyecto que permite agregar, seleccionar y eliminar imágenes dinámicamente usando manipulación del DOM.

## Funcionalidades
- Agregar imágenes mediante URL.
- Seleccionar una imagen con clic.
- Resaltar imagen seleccionada.
- Eliminar imagen seleccionada.
- Atajos de teclado:
  - Enter → Agregar imagen
  - Delete → Eliminar imagen seleccionada

## Tecnologías
- HTML5
- CSS3
- JavaScript
